# Notification Sound Files

Place your notification sound files here:

- `chime.mp3` - A gentle chime sound
- `bell.mp3` - A bell ring
- `ding.mp3` - A quick ding sound  
- `pop.mp3` - A pop sound

## Where to Get Free Notification Sounds

1. **Notification Sounds**: https://notificationsounds.com/
2. **Freesound**: https://freesound.org/ (requires free account)
3. **Mixkit**: https://mixkit.co/free-sound-effects/notification/
4. **Zapsplat**: https://www.zapsplat.com/sound-effect-categories/

## Recommended Settings

- Format: MP3
- Duration: 1-3 seconds
- Sample Rate: 44.1kHz
- Bitrate: 128kbps or higher

## Temporary Workaround

The system will gracefully handle missing sound files. If a sound file is not found, the notification will still appear but without sound.
